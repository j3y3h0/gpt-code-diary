# JSON 판매 데이터 분석 프로젝트

## 1. 프로젝트 설명

이 프로젝트는 C#으로 구현된 소규모 콘솔 애플리케이션으로, JSON 형식의 판매 데이터를 읽어들여 제품별 총 판매액을 분석하는 도구입니다. 산업 표준 라이브러리인 `System.Text.Json`을 사용하여 JSON 데이터를 처리하며, 실용적이고 확장 가능한 코드 구조를 지향합니다.

## 2. 코드 구조

프로젝트는 다음과 같은 파일들로 구성되어 있습니다.

-   **`SalesAnalysisApp.csproj`**: C# 프로젝트 파일입니다. .NET 8.0을 대상으로 하며, 필요한 종속성과 프로젝트 설정을 정의합니다.
-   **`Program.cs`**: 애플리케이션의 진입점입니다. `sales.json` 파일에서 판매 데이터를 읽고, `SalesAnalyzer` 클래스를 사용하여 데이터를 분석한 후, 결과를 콘솔에 출력하는 역할을 합니다.
-   **`SalesData.cs`**: 판매 데이터와 관련된 C# 데이터 모델(예: `Sale`, `Product` 레코드)을 정의합니다. `System.Text.Json.Serialization` 특성을 사용하여 JSON 직렬화/역직렬화 방식을 지정합니다.
-   **`SalesAnalyzer.cs`**: 판매 데이터를 분석하는 비즈니스 로직을 포함하는 정적(static) 클래스입니다. 제품별 총 판매액 계산과 같은 핵심 분석 기능을 제공합니다.
-   **`sales.json`**: 애플리케이션이 읽을 샘플 JSON 판매 데이터 파일입니다. 실제 판매 기록들이 배열 형태로 포함되어 있습니다.
-   **`README.md`**: 현재 이 문서로, 프로젝트에 대한 전반적인 설명, 코드 구조, 그리고 실행 방법을 안내합니다.

## 3. 실행 방법

이 프로젝트를 실행하려면 시스템에 .NET 8.0 SDK 이상이 설치되어 있어야 합니다.

1.  **파일 준비**: 모든 `.cs`, `.csproj`, `.json` 파일이 현재 디렉터리(`C:\server\gpt-code-diary\codes\202607\28`)에 위치하는지 확인하십시오.
2.  **터미널 열기**: 해당 디렉터리에서 터미널(예: PowerShell, 명령 프롬프트)을 엽니다.
3.  **애플리케이션 실행**: 다음 명령어를 입력하여 애플리케이션을 실행합니다.

    ```bash
    dotnet run
    ```

4.  **결과 확인**: 콘솔에 제품별 총 판매액 분석 결과가 출력되는 것을 확인할 수 있습니다.

## 4. 사용 라이브러리

-   **`System.Text.Json`**: .NET Core 및 .NET 5+에서 기본 제공하는 고성능 JSON 처리 라이브러리입니다. JSON 데이터의 직렬화 및 역직렬화에 사용됩니다.

## 5. 주의사항

-   `sales.json` 파일이 존재하지 않거나 유효한 JSON 형식이 아닐 경우, 애플리케이션은 오류 메시지를 출력하고 종료될 수 있습니다.
-   본 프로젝트는 .NET 8.0 환경에서 테스트되었습니다. 다른 버전의 .NET 환경에서는 호환성 문제가 발생할 수 있습니다.

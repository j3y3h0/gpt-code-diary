# 간단한 AI 기반 키워드 추출 프로젝트

## 프로젝트 설명
이 프로젝트는 AI 기반 자연어 처리(NLP)의 기초적인 개념을 사용하여 텍스트에서 주요 키워드를 추출하는 간단한 예시입니다. 복잡한 머신러닝 모델 대신, 텍스트 토큰화, 불용어(Stop Words) 제거 및 단어 빈도수 계산과 같은 기본적인 통계적 방법을 활용하여 핵심 단어를 식별합니다. 이는 실제 산업에서 사용되는 키워드 추출 알고리즘의 기초적인 원리를 보여줍니다.

## 파일 구조
-   `README.md`: 이 프로젝트에 대한 설명과 실행 방법을 담고 있습니다.
-   `main.js`: 애플리케이션의 주 진입점입니다. `data.js`에서 샘플 텍스트를 가져와 `nlpUtils.js`의 함수들을 사용하여 키워드를 추출하고 결과를 출력합니다.
-   `nlpUtils.js`: 자연어 처리에 필요한 유틸리티 함수들을 모아둔 파일입니다. 텍스트를 단어로 나누는 `tokenize`, 불필요한 단어를 제거하는 `removeStopWords`, 그리고 최종적으로 키워드를 추출하는 `extractKeywords` 함수가 포함되어 있습니다.
-   `data.js`: 키워드 추출 대상이 되는 샘플 텍스트 데이터가 저장되어 있습니다.

## 실행 방법
프로젝트를 실행하려면 Node.js가 설치되어 있어야 합니다. 터미널 또는 명령 프롬프트에서 다음 명령어를 입력합니다:

```bash
node main.js
```

실행 결과로 각 샘플 텍스트에서 추출된 키워드 목록이 출력될 것입니다.

## 사용 기술
-   **JavaScript**: 모든 코드 파일은 JavaScript로 작성되었습니다.
-   **기본적인 자연어 처리 알고리즘**: 토큰화, 불용어 제거, 빈도수 기반 키워드 추출.
